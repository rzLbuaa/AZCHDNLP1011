# Local validation

The release was exercised under Python 3.13.5 on Linux. All 86 tests passed with no failures or skips. Source compilation, wheel construction, isolated wheel installation, the fifteen-entry offline demonstration and the standalone D entry point were executed.

The demonstration completed 120 arm-record evaluations from eight synthetic queries. This is a software completion check, not a clinical result or fifteen independent trials. R0 aliases A, and several controls reuse A generation.

Tests cover label isolation, frozen A/C retrieval, exact A/D generation reuse, missingness, quotation boundaries, high-risk connection constraints, failure handling, manifest identity, resource hashes, HTTP response envelopes, retries, paired statistics and crossed-reader analysis. HTTP tests use MockTransport; no live model service was called.

The supplied GitHub workflow has not run on GitHub in this release environment. Ruff was not available locally; no local Ruff pass is claimed. The archive contains no clinical predictions, private request payloads, caches or original patient records.
