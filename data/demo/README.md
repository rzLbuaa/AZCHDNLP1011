# Demonstration fixtures

All descriptions in this directory are invented software-test fixtures. They contain no clinical records and do not reproduce the manuscript cohort, ontology, ratings, or reported performance. The deterministic demo backend shares the small rulebook with verification; its outputs measure plumbing, not clinical or model effectiveness. Reference labels are supplied separately and are never read during inference.
